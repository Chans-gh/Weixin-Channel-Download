常见问题

  • 安装与故障排查指南
  • 宿主兼容性记录
需要准备什么运行环境？

准备 Node.js 24+ 与 npm，并在技能目录运行 npm ci --ignore-scripts。分享链接需要 Google Chrome、可交互桌面和网络。导入媒体、提取音轨和准备转写还需要 FFmpeg 和 ffprobe。

为什么下载链接时要登录元宝？

Skill 通过元宝解析分享链接。按提示在临时 Chrome 窗口登录后，原任务会自动继续。默认等候约 3 分钟，超时可重跑。导入本地文件时可直接处理。

Agent 无法接收音频时，还能转写吗？

可以用本地 Whisper Base q8 继续同一任务。首次使用需下载并校验约 80 MB 的模型，缓存后可离线识别。遇到音轨不清晰时，可用同一编号重试或跳过口播。

文件保存在哪里？

默认保存到本机 Downloads，也可以向 Agent 指定输出目录。遇到同名文件时追加序号。发布文案和口播稿单独记录。
